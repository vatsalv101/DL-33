# Paper 26: Auto-Encoding Variational Bayes (VAE)

> **"How do we learn directed probabilistic latent-variable models in the presence of continuous latent variables whose marginal likelihood and posterior distributions are analytically intractable?"**
> — Diederik P. Kingma & Max Welling (ICLR 2014)

---

## 1. The Breaking Point: The Gap Between Compression and Generation

Prior to 2013, deep unsupervised representation learning was dominated by deterministic Autoencoders (AEs) and energy-based models (Restricted Boltzmann Machines). Standard autoencoders map an input $x \in \mathbb{R}^D$ to a low-dimensional bottleneck code $z = e_\phi(x) \in \mathbb{R}^d$ and reconstruct $\hat{x} = d_\theta(z) \approx x$.

While effective for dimensionality reduction and non-linear PCA, standard autoencoders fail catastrophically as **generative models**:

```
Deterministic Autoencoder Latent Topology:
------------------------------------------
z-space:  [ Cluster A ]  <--- Void / Garbage --->  [ Cluster B ]
             (digit 1)                                (digit 7)
Sampling z_random from the void produces invalid, blurry hallucinations!
```

1. **Topological Discontinuity & Holes**: Without an explicit density constraint, an unconstrained deterministic encoder places codes arbitrarily in latent space. The latent space is full of "holes" where no training data mapped. Drawing a random vector $z \sim \mathcal{N}(0, I)$ and passing it to the decoder produces incomprehensible artifacts.
2. **Intractability of the True Marginal Likelihood**: In a true directed generative model, data is assumed to be generated by a prior $p(z)$ and a conditional likelihood $p_\theta(x|z)$:
   $$p_\theta(x) = \int p_\theta(x|z) p(z) \, dz$$
   For non-linear neural network decoders $p_\theta(x|z)$, this high-dimensional integral is analytically intractable.
3. **Intractability of the True Posterior**: By Bayes' rule:
   $$p_\theta(z|x) = \frac{p_\theta(x|z) p(z)}{p_\theta(x)}$$
   Because the normalizing constant $p_\theta(x)$ cannot be computed, computing the true posterior $p_\theta(z|x)$ is equally impossible.
4. **Failure of Classical MCMC / Mean-Field Variational Inference**: Traditional Monte Carlo Markov Chain (MCMC) sampling is far too slow for web-scale datasets, requiring inner-loop sampling per gradient step. Traditional variational inference requires restrictive conjugate priors that break when combined with deep neural networks.

## 2. The Thought Experiment: The Smooth Elastic Sheet

Imagine stretching an elastic sheet over a coordinate plane centered at the origin $(0, 0)$.

- If you allow each data point $x$ to be an isolated iron weight, the encoder drops weights across the sheet with huge distances between them. Interpolating between two data points falls into empty territory.
- Now suppose every point $x$ is not a point, but a **cloud of mist** with mean $\mu(x)$ and variance $\sigma^2(x)$.
- Furthermore, you attach a spring pulling every cloud towards the center $\mathcal{N}(0, I)$ (the Prior).
- The decoder must learn to reconstruct $x$ when sampled from **anywhere within the mist**.

```
                Encoder q_phi(z|x)
Input x ---------------------------------> mu(x), log_var(x)
                                                |
                                                v
Prior Regularizer:                         z = mu + sigma * eps
D_KL(q(z|x) || N(0, I))                         |
"Pull mist towards origin"                      v
                                         Decoder p_theta(x|z)
                                       ---------------------> Reconstruction x_hat
```

Two competing forces emerge:
1. **The Reconstruction Force** pushes clouds apart and makes variances small so the decoder can distinguish inputs and reconstruct fine details.
2. **The KL Divergence Force** pulls all clouds toward $\mathcal{N}(0, I)$, ensuring overlap, continuous interpolation, and eliminating empty regions.

Generative sampling simply becomes: sample $z \sim \mathcal{N}(0, I)$ and decode $\hat{x} \sim p_\theta(x|z)$!

## 3. Mathematical Derivation: ELBO & The Reparameterization Trick

### 3.1 The Evidence Lower Bound (ELBO)

Let $q_\phi(z|x)$ be an amortized variational approximation to the intractable true posterior $p_\theta(z|x)$, parameterized by an encoder neural network with weights $\phi$.

We expand the log-marginal likelihood $\log p_\theta(x)$:
$$\log p_\theta(x) = \mathbb{E}_{q_\phi(z|x)} [\log p_\theta(x)] = \mathbb{E}_{q_\phi(z|x)} \left[ \log \frac{p_\theta(x, z)}{q_\phi(z|x)} \frac{q_\phi(z|x)}{p_\theta(z|x)} \right]$$

Distributing the expectation:
$$\log p_\theta(x) = \mathbb{E}_{q_\phi(z|x)} \left[ \log \frac{p_\theta(x, z)}{q_\phi(z|x)} \right] + \mathbb{E}_{q_\phi(z|x)} \left[ \log \frac{q_\phi(z|x)}{p_\theta(z|x)} \right]$$

The second term is the definition of the Kullback-Leibler (KL) divergence between the variational posterior and the true posterior:
$$\log p_\theta(x) = \mathcal{L}_{\text{ELBO}}(\theta, \phi; x) + D_{\text{KL}}(q_\phi(z|x) \parallel p_\theta(z|x))$$

Since $D_{\text{KL}}(\cdot \parallel \cdot) \ge 0$ by Gibbs' inequality:
$$\log p_\theta(x) \ge \mathcal{L}_{\text{ELBO}}(\theta, \phi; x)$$

Expanding the ELBO:
$$\begin{aligned}
\mathcal{L}_{\text{ELBO}}(\theta, \phi; x) &= \mathbb{E}_{q_\phi(z|x)} \left[ \log \frac{p_\theta(x|z) p(z)}{q_\phi(z|x)} \right] \\
&= \underbrace{\mathbb{E}_{q_\phi(z|x)} [\log p_\theta(x|z)]}_{\text{Reconstruction Likelihood}} - \underbrace{D_{\text{KL}}(q_\phi(z|x) \parallel p(z))}_{\text{Latent Prior Regularizer}}
\end{aligned}$$

To train the VAE via gradient descent, we **minimize the negative ELBO**:
$$\mathcal{L}_{\text{VAE}} = -\mathbb{E}_{q_\phi(z|x)}[\log p_\theta(x|z)] + D_{\text{KL}}(q_\phi(z|x) \parallel p(z))$$

---

### 3.2 Closed-Form Gaussian KL Divergence

Assuming standard isotropic Gaussian prior $p(z) = \mathcal{N}(0, I)$ and diagonal Gaussian variational posterior $q_\phi(z|x) = \mathcal{N}(\mu, \operatorname{diag}(\sigma^2))$ where $\mu, \log \sigma^2 \in \mathbb{R}^d$:

$$D_{\text{KL}}(q_\phi(z|x) \parallel p(z)) = \int q(z) \log \frac{q(z)}{p(z)} dz$$

For two multivariate normal distributions with diagonal covariances:
$$D_{\text{KL}}(\mathcal{N}(\mu, \operatorname{diag}(\sigma^2)) \parallel \mathcal{N}(0, I)) = -\frac{1}{2} \sum_{j=1}^d \left( 1 + \log(\sigma_j^2) - \mu_j^2 - \sigma_j^2 \right)$$

Letting $s_j = \log(\sigma_j^2)$ (the network output `logvar`):
$$D_{\text{KL}} = -\frac{1}{2} \sum_{j=1}^d \left( 1 + s_j - \mu_j^2 - \exp(s_j) \right)$$

When $\mu_j = 0$ and $s_j = 0$ ($\sigma_j^2 = 1$), $1 + 0 - 0 - 1 = 0$, giving exact zero divergence!

---

### 3.3 The Core Bottleneck: Gradient of an Expectation

We need to differentiate the reconstruction term with respect to encoder parameters $\phi$:
$$\nabla_\phi \mathbb{E}_{q_\phi(z|x)} [f(z)]$$

Standard Monte Carlo sampling draws $z^{(l)} \sim q_\phi(z|x)$. However, the sampling distribution itself depends on $\phi$! Direct differentiation yields high-variance score-function estimators (REINFORCE):
$$\nabla_\phi \mathbb{E}_{q_\phi(z|x)} [f(z)] = \mathbb{E}_{q_\phi(z|x)} [f(z) \nabla_\phi \log q_\phi(z|x)] \quad \text{(Extremely noisy)}$$

---

### 3.4 The Reparameterization Trick

Kingma & Welling's insight was to decompose the random variable $z$ into a deterministic mapping of inputs, parameters, and an auxiliary independent noise variable $\epsilon$:

$$\epsilon \sim \mathcal{N}(0, I)$$
$$z = g_\phi(x, \epsilon) = \mu(x) + \sigma(x) \odot \epsilon = \mu(x) + \exp\left(\frac{1}{2}\log \sigma^2(x)\right) \odot \epsilon$$

```
Standard Stochastic Node (Non-differentiable):
  x, phi ----> [ q_phi(z|x) ] ~~~~> z ----> Decoder p_theta(x|z)
                                    ^
                             Gradient BLOCKED!

Reparameterized Graph (Fully Differentiable):
  eps ~ N(0, I) (No parameters!)
        |
        v
  x, phi ----> [ mu, logvar ] ----> [ z = mu + exp(0.5 * logvar) * eps ] ----> Decoder
                      |                              |
                      +------------------------------+
                         Backprop flows smoothly!
```

By the law of the unconscious statistician:
$$\nabla_\phi \mathbb{E}_{q_\phi(z|x)} [f(z)] = \nabla_\phi \mathbb{E}_{p(\epsilon)} [f(g_\phi(x, \epsilon))] = \mathbb{E}_{p(\epsilon)} \left[ \nabla_z f(z) \cdot \nabla_\phi g_\phi(x, \epsilon) \right]$$

Now the expectation is over $p(\epsilon)$ which has zero dependence on $\phi$. A single sample $\epsilon \sim \mathcal{N}(0, I)$ per batch element provides an unbiased, low-variance estimator that backpropagates cleanly with standard autodiff!

## 4. Tensor Contracts & Architectural Topology

```
                       Input Image x: (B, C, H, W)
                                  |
                                  v
                        [ Conv Encoder Backbone ]
                                  |
                                  v
                        Flattened: (B, H_feat)
                             /         \
                            /           \
                 Linear    /             \ Linear
                          v               v
                mu: (B, D_latent)    logvar: (B, D_latent)
                          \               /
                    eps ~ N(0, I): (B, D_latent)
                            \           /
                             v         v
                      z = mu + exp(0.5 * logvar) * eps
                                  |
                           z: (B, D_latent)
                                  |
                                  v
                         [ Linear Projector ]
                                  |
                           (B, C_dec, H', W')
                                  |
                                  v
                        [ ConvTranspose Decoder ]
                                  |
                                  v
                    Reconstruction x_hat: (B, C, H, W)
```

### Tensor Dimensions
- Input $x$: `(B, C, H, W)` in range $[0, 1]$ or $[-1, 1]$.
- Latent Mean $\mu$: `(B, D_latent)`
- Latent Log-Variance $\log \sigma^2$: `(B, D_latent)`
- Latent Sample $z$: `(B, D_latent)`
- Reconstructed Output $\hat{x}$: `(B, C, H, W)`

## 5. Downstream Unlocks

1. **Conditional VAE (CVAE)**: Conditioning $q_\phi(z|x, y)$ and $p_\theta(x|z, y)$ on class labels $y$ or robot trajectories enable controllable class-guided generation.
2. **$\beta$-VAE**: Introducing $\beta > 1$ into $\mathcal{L} = \text{Recon} + \beta D_{\text{KL}}$ forces statistical independence among latent channels, unlocking disentangled representations (e.g. azimuth, scale, illumination).
3. **VQ-VAE & VQ-GAN**: Discretizing $z$ via vector quantization solves VAE blurriness and forms the visual tokenizer foundation for DALL-E and Part-1 Transformers.
4. **Latent Diffusion Models (Stable Diffusion)**: VAE encoders compress high-resolution image space $(H, W, 3)$ into compact latent feature space $(H/8, W/8, 4)$, enabling modern diffusion models to train efficiently.
